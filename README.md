# ✅ Todo List App

A simple console-based Todo List application built using HTML and JavaScript. It allows users to add, view, and delete tasks through interactive browser prompts.

## 📌 About the Project

The Todo List App is a beginner-friendly project created to practice JavaScript fundamentals. The webpage displays instructions for available commands, while JavaScript handles task management using arrays, loops, conditional statements, and built-in array methods.

Users can add new tasks, view existing tasks with their indexes, delete tasks, and quit the application.

## ✨ Features

- **Add Tasks:** Add new tasks to the todo list.
- **List Tasks:** Display all tasks with their respective indexes.
- **Delete Tasks:** Remove a task by entering its index.
- **Interactive Prompts:** Enter commands and task details through browser prompts.
- **Quit Option:** Exit the application using the `Quit` command.
- **Command Instructions:** View available commands on the webpage.

## 🛠️ Technologies Used

- **HTML5** — Structures the webpage and displays instructions.
- **JavaScript** — Implements the todo list functionality.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in a web browser.
4. Enter commands in the browser prompts.
5. Open the browser developer console to view tasks and status messages.

## 🎮 Available Commands

| Command | Description |
|---|---|
| `List` | Displays all tasks with their indexes. |
| `Add` | Adds a new task to the list. |
| `Delete` | Deletes a task using its index. |
| `Quit` | Exits the application. |

**Note:** Commands are case-sensitive. Enter them exactly as shown above.

## 🧠 JavaScript Concepts Used

- Arrays
- `while` and `for` loops
- `if-else` conditional statements
- `prompt()` for user input
- `console.log()` for displaying output
- `push()` to add tasks
- `splice()` to delete tasks
- Array indexing and the `length` property
- `break` statement

## ⚠️ Limitations

- Tasks are stored temporarily in an array.
- Tasks are lost when the page is refreshed or the application is restarted.
- Invalid task indexes are not explicitly validated.
- The task list and status messages are displayed in the browser console rather than directly on the webpage.
